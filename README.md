# Tasting Notes

実際に飲んだお酒の味・香り・飲み口などを、日本語で記録する個人のテイスティングノートです。記録は執筆者の主観的な感想です。

## 分類

- `01_Whisky/`：ウイスキー
- `02_Beer/`：ビール
- `03_Liqueur/`：リキュール
- `04_Wine/`：ワイン
- `05_Sake/`：日本酒
- `06_Shochu/`：焼酎

フォルダ名の数字は表示順を揃えるための接頭辞です。必要に応じて分類を追加します。空の分類には `.gitkeep` を置きます。

## 記録の管理

- 原則として商品ごとに1つの `.txt` ファイルを作り、UTF-8で保存します。
- ファイル名はラベルの商品名を基準に、国内ブランドは日本語、海外ブランドは原語表記にします。英語圏以外の商品はラベルや公式サイトの英字表記も使えます。空白はそのまま使い、年数・限定版・缶と瓶などの区別を残します。
- 商品の種類を特定できない場合は、推測で名称を補いません。感想本文の商品名は元の表記を保持します。
- 同じ商品を再び飲んだ際は、同じファイルに日付付きで追記し、過去の感想を残します。
- 通常版と限定版など、明確に異なる商品は別ファイルにします。既存の缶・瓶の記録も分けて保持しています。
- 書式は自由です。既存の記録にない日付は補いません。ワインの商品名に含まれる年は、そのまま保持しています。
- 商品名だけで感想が未記入のファイルもあります。
